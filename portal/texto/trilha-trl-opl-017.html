Trilha do Profissional em Operações Offshore

Código
TRL-OPL-017
Área CNCT
Operação e Manutenção Offshore
CBO
3111-05

Capacita o egresso para atuar em plataformas offshore, com preendendo projeto estrutural, sistemas de ancoragem, dutos submarinos, integridade de equipamentos e segurança operacional, com base em normas ISO, API e DNV.

Etapas e onde estudar

  1. M1 — Fundamentos de Engenharia Offshore
    • ISO 19901 Series — ISO 19901 Series (https://www.iso.org/standards)
    • Petrobras — Engenharia Submarina (https://publicacoesup.petrobras.com.br/)
  2. M2 — Sistemas de Ancoragem e Dutos Submarinos
    • DNV Standards — DNV Standards (https://www.dnv.com/)
    • COPPE/UFRJ — LAMCSO (https://www.lamcso.coppe.ufrj.br/)
  3. M3 — Estruturas e Topside
    • ISO 19901-3:2024 — ISO 19901-3:2024 (https://webstore.ansi.org/)
    • API RP 2A-WSD — API RP 2A-WSD (https://www.api.org/products-and-services/standards)
  4. M4 — Integridade e Inspeção Offshore
    • ISO 19901-9:2019 — ISO 19901-9:2019 (https://www.iso.org/)
    • Marinha do Brasil — Procedimentos (https://www.marinha.mil.br/dpc/normas-normam)
  5. M5 — Projeto Final: Sistema Offshore
    • Mentoria COPPE / Petrobras — Mentoria COPPE / Petrobras (https://publicacoesup.petrobras.com.br/)

Sub-trilhas

  • Módulo: Perfuração HPHT e Águas Ultraprofundas — Fluidos especiais, equipamentos, geomecânica, integridade de poços

Sub-trilha: CLP Avançado — Programação Estruturada, ST e SFC

Código
TRL-SUB-001
Área CNCT
Automação e Controle de Processos
CBO
3111-15
Derivada de
Trilha do Profissional em Automação Industrial

Sub-trilha avançada para técnicos que desejam dominar linguagens de programação estruturada (ST), Sequential Function Chart (SFC) e boas práticas de engenharia de software para CLPs, com base em normas IEC 61131-3, manuais de fabricantes (Siemens, Rockwell, Schneider) e estudos de caso indus

Etapas e onde estudar

  1. M1 — Revisão de IEC 61131-3 e Estruturas de Dados
    • ISA — IEC 61131-3 Standards (https://www.isa.org/standards-and-publications/isa-standards)
    • Siemens — TIA Portal Programming Guidelines (https://support.industry.siemens.com)
  2. M2 — Programação Estruturada em ST (Structured Text)
    • Rockwell Automation — ST Programming Manual (https://www.rockwellautomation.com/)
    • Schneider Electric — EcoStruxure ST Guide (https://www.se.com/)
  3. M3 — Sequential Function Chart (SFC) e Máquinas de Estado
    • Siemens — SFC Programming Guide (https://support.industry.siemens.com)
    • ISA — Batch Control (ISA-88) (https://www.isa.org/standards-and-publications/isa-standards)
  4. M4 — Boas Práticas e Depuração Avançada
    • SENAI Play — CLP Avançado (https://play.senai.br/)
  5. M5 — Projeto Final: Máquina de Estado para Processo Industrial
    • Mentoria SENAI — Mentoria SENAI (https://www.portaldaindustria.com.br/senai/)
